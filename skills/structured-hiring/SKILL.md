# 结构化招聘

## 原则

1. **先定义尺子，再筛人**：开岗时和用人经理共同确定考察维度、权重、必备项、硬性条件。
2. **每一分都有证据**：初筛输出必须能指到简历原文；缺必备能力只给「待定」，不粉饰。
3. **独立反馈**：面试官提交自己的评价前看不到别人的；招聘经理可例外。
4. **用数据校准**：看初筛分档 vs 后续通过率、面试官打分偏差、阶段停留 vs 时限。

## 产出模板

当用户要设计某个岗位流程时，按下面顺序交付：

1. **评分卡**：5 个以内维度（名称 / 权重 / 是否必备 / 证据关键词）
2. **硬性条件**：学位、到岗、地点等（不参与打分，不符直接不推荐）
3. **面试工具包**：电话面 2 题 + 现场面 4 题，每题绑定一个维度
4. **推进规则**：反馈收齐才能推进；分歧 ≥ 2 档或有人强烈不推荐 → 复盘会
5. **校准指标**：漏斗、渠道质量、面试官平均总评 vs 全体、淘汰原因

## 禁止

- 不要用「感觉不错」「综合素质强」代替行为证据
- 拒信不要写具体淘汰原因；内部淘汰原因必须结构化编码，方便分析
- 不要把真实候选人敏感信息写进示例
