# Playbook · 舆情洞察到话术质检 SOP

适用：社媒 / 社群评论 → 管理层建议 → 一线话术，且需要发布前拦截。  
演示：[VOC Insight Kit](https://annawzhang.github.io/voc-insight-kit/)

## 流程

```text
评论快照 → 去重（合并点赞）→ 议题编码 → 情感（否定词翻转）
        → 点赞加权 / 价格关口 →「问题·结论·原声」
        → 定价/上市/传播建议 + 四步话术 → 禁止话术检查 → 发布
```

## 编码本原则

- 议题数量可控（示例 7 个），每条评论可多标签但主议题唯一
- 统计同时给「按条」和「点赞加权」，避免灌水带偏
- 价格类议题要抽具体价位点，找负面占比首次过半的关口

## 四步话术（门店可用）

1. **认同**：先接住情绪，不争对错  
2. **重构**：用可验证事实改框架  
3. **转移**：接到产品真正优势  
4. **落地**：给下一步动作（试驾 / 对比表 / 政策）

## 禁止话术检查（必须自动化）

示例拦截类型（配置化，勿写死品牌内部黑话）：

- 贬低竞品人身 / 造谣规格  
- 绝对化承诺（「一定升值」「零故障」）  
- 未备案的价格/政策口径  
- 引导私下转账、绕过正规下单

命中即拦截并给出规则编码与修改建议，不允许「先发后改」。

## 周复盘

- [ ] 哪一议题热度上升？话术是否已更新  
- [ ] 禁止话术命中率：是话术写得冒险，还是一线擅自发挥  
- [ ] 建议是否进入经营动作（定价会 / 上市节奏 / 传播选题）
