# Playbook · 业务群触达审批 SOP

适用：日报 / 晾晒 / 激励榜 / 预警卡片等需要往业务群发的内容。  
演示：[Sales Ops Assistant](https://annawzhang.github.io/sales-ops-assistant/)

## 核心问题（发之前必须能回答）

1. 数据新不新？
2. 数字对不对？（覆盖率、异常值）
3. 现在该不该发？（时间窗）
4. 该发给谁？（白名单，不是「所有群」）
5. 发错了能不能查？（message_id + 审计日志）

## 标准流程

```text
意图路由 → 幂等锁 / 时间窗 → 刷新数据 → 健康检查 → 渲染
        → 预览确认（首次或大批量必审）→ 按固定顺序发送 → 留痕
```

## 检查清单

- [ ] 同一任务同一天同一半天只执行一次（防重复）
- [ ] 数据源失败：完整重跑一次，仍失败则不发并通知负责人
- [ ] 发送窗口外自动停止（示例：08:30–21:00）
- [ ] 健康检查不过不发（覆盖率 / 新鲜度 / 数值合理性）
- [ ] 禁言群、含外部成员的敏感群跳过或拦截
- [ ] 越权「发到所有群」类意图直接拒绝
- [ ] 每条消息带可追溯 ID，步骤写入审计日志

## 产品化提示

把 SOP 写进配置与代码护栏，而不是只写在文档里。预览 → 授权 → 群发是产品界面，幂等与健康检查是引擎。
