# Playbook · 结构化招聘 SOP

适用：开新岗、校准面试标准、评审 ATS / 招聘助手产品。  
演示：[Hiring Copilot](https://annawzhang.github.io/hiring-copilot/)

## 1. 开岗（Day 0）

- [ ] 用人经理 + 招聘经理一起写评分卡（≤ 5 维，权重归一，标必备）
- [ ] 写清硬性条件（地点 / 到岗 / 学历等）
- [ ] 为电话面、现场面各准备工具包问题，每题绑定一个维度
- [ ] 约定阶段时限（例如新简历 3 天、现场面 7 天、Offer 5 天）

## 2. 初筛

- [ ] 按评分卡打分，列出命中的简历原句
- [ ] 硬性条件不符 → 不推荐；缺必备 → 待定
- [ ] 可选盲筛：隐藏姓名 / 性别 / 年龄 / 学校

## 3. 面试

- [ ] 面试官只评自己负责的维度，写 ≥ 15 字行为依据
- [ ] 提交前不可见他人反馈
- [ ] 收齐后汇总：均分、分歧、是否「强烈不推荐」

## 4. 决策

| 情况 | 动作 |
|---|---|
| 建议录用且名额未满 | 发 Offer |
| 建议不通过 | 结构化淘汰原因 + 礼貌拒信（不写原因细节） |
| 需要复盘会 | 先对齐标准，再决定是否推进 |

## 5. 每周复盘

- [ ] 漏斗哪一步掉得最多？
- [ ] 初筛高分是否更易通过现场面？（评分卡是否有效）
- [ ] 谁偏宽松 / 偏严格？（±0.4 分提示校准）
- [ ] 哪类淘汰原因占比异常？要不要改 JD 或渠道
